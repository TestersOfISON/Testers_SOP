Jira & Confluence Cloud: The "To-Be" UI Guide

This document provides a comprehensive overview of the upcoming migration from Data Center to Cloud, specifically focusing on the new "To-Be" UI, new capabilities, and critical changes. The goal is to ensure a smooth transition for all Project Managers and team members.

1. The New Global Navigation

In the Cloud environment, the traditional top horizontal navigation bar has been replaced by a modern, vertical global sidebar. This provides faster access to your most important work without relying on hidden dropdown menus.

Figure 1: The new vertical global sidebar in Jira Cloud.
  • Your Work: Quick access to assigned, recent, and starred issues.
  • Projects: A fast project switcher directly in the sidebar.
  • Global Search: Semantic search powered by AI, finding both Jira issues and Confluence pages.

2. Modernized Issue View

The ticket view has been completely overhauled. It moves away from the rigid, fixed layout of Data Center to a modular, resizable view that makes scanning information much faster.

Figure 2: The modular issue view with inline attachments and AI intelligence panels.
  • Main Area: Child issues and sub-tasks are highly prominent. Attachments are now displayed inline within the description.
  • Right Panel: Status, assignees, and custom fields are neatly organized.
  • Atlassian Intelligence: Rovo AI is integrated directly into the ticket, allowing you to automatically summarize comments or generate descriptions.

3. Confluence Whiteboards & Collaboration

Confluence has received massive upgrades, introducing Native Whiteboards and Databases to replace external tools like Miro or ad-hoc Excel spreadsheets.

Figure 3: Agile story mapping using Confluence Whiteboards.
  • Direct Jira Integration: You can select any sticky note on the whiteboard and convert it directly into a live Jira issue with one click.
  • Real-time Co-editing: Edit Confluence pages with multiple team members simultaneously without page locking.
  • Smart Links: Pasting a Jira URL automatically renders an interactive card showing real-time status.

4. Quick Cheat Sheet

Action Data Center (Old) Cloud (To-Be)
Create Issue 'Create' in top bar '+' icon in global sidebar
Change Project Project dropdown menu Project switcher in sidebar
Saved Filters Filters menu top 'Starred' in Your Work sidebar
Search Cmd + . '/' shortcut or global bar

5. Post-Migration Action Plan

We recommend following this structured plan in your first 90 days:

  • Week 1: Familiarize yourself with the UI, log in, and save your most-used filters to "Starred". Try the new Jira Mobile app.
  • Month 1: Replace an old spreadsheet with a Confluence Database and build 2-3 Automation rules to save time.
  • Day 90: Standardize automation across your Scrum team, clean up unused boards, and migrate weekly reporting to AI summaries.
