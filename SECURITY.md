# Security Policy

## Supported Versions

We take the security of the Libra SOP Portal very seriously. We actively support and provide security patches for the following deployment environments:

| Version | Supported          |
| ------- | ------------------ |
| Main (Live deployed) | :white_check_mark: |
| Staging / Dev Branches | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within the Libra SOP Portal (e.g., exposed API keys, cross-site scripting, unauthorized admin access), please DO NOT open a public GitHub issue.

Instead, please report the vulnerability privately by emailing our security team at:
**security@librabank.com** *(Placeholder - update as needed)*

### What to include in your report:
* A detailed description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact or risk assessment.

### Our Response Process:
1. We will acknowledge receipt of your vulnerability report within 48 hours.
2. We will investigate the issue and determine the severity.
3. If confirmed, we will issue a patch and notify you once it is deployed to the live environment.

Thank you for helping keep Libra Bank secure.
